# Mutual Fund Analytics Dashboard

A presentation-ready Streamlit dashboard for the Bluestock Fintech Data Analytics Internship.

## Features
- Market Overview: SIP trend, AMC AUM, category inflows, KPIs
- Fund Performance & Risk: returns, volatility, Sharpe, Sortino, drawdown and scorecard
- Investor Analytics: transaction mix, state, age group, city tier and KYC views
- Portfolio Holdings: holdings, sector exposure and stock-level detail
- Global AMC and category filters
- Uses the supplied project database and datasets — no random/simulated NAV data is generated by the dashboard

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL shown by Streamlit.

## Demo talking points
1. Start on Market Overview and show the KPI cards.
2. Select an AMC from the sidebar and move to Fund Performance & Risk.
3. Point out Sharpe/Sortino/volatility/drawdown and the interactive fund table.
4. Open Investor Analytics and explain the transaction-level analysis.
5. Finish on Portfolio Holdings to demonstrate the full analytics workflow.
